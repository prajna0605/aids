How to Verify the Model

To verify the system on real clinical data without any simulation:

  1. Click Browse ECG File and select data/mitbih_test.csv from this repository (contains 4,500 real clinical beats with AAMI labels).
  2. Click Analyze ECG File. The system will reconstruct the real continuous rhythm strip, locate R-peaks, and flag anomalous beats.
  3. Check the Benchmarks page to view the quantitative validation matrix (96.9% accuracy, 93.8% recall, 97.8% specificity).
