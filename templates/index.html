How It Works

4 simple automated steps from raw recording to anomaly detection

1. Filter Noise

Zero-phase bandpass filter removes breathing baseline drift and 50Hz electrical hum.

2. Find R-Peaks

Pan-Tompkins algorithm pinpoints each heartbeat spike with physiological timing locks.

3. Extract Features

Measures beat-to-beat RR timing intervals, QRS width, voltage amplitude, and waveform energy.

4. Flag Anomalies

Machine learning model compares beats and highlights premature or irregular contractions.
