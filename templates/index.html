How ECG Insight AI Works

End-to-end biomedical machine learning telemetry pipeline

1. Zero-Phase DSP

Butterworth bandpass (0.5–40 Hz) and notch filters eliminate respiration baseline wander and EMG noise without temporal phase distortion.

2. Pan-Tompkins QRS

Multi-stage differentiation, non-linear squaring, moving window integration, and a 250ms physiological refractory lock precisely localize R-peaks.

3. Feature Extraction

Extracts 30 biomedical dimensions per beat: QRS area, peak-to-peak amplitude, ST level, statistical kurtosis, and HRV timing dynamics (Pre/Post RR).

4. ML Anomaly Scoring

Isolation Forest isolates rare ectopic morphologies (e.g. PVCs and PACs) into a normalized continuous score [0, 1] with real-time telemetry alerts.
